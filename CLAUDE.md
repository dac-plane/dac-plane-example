# Agent guide: dac-plane example

`AGENTS.md` is a symlink to this file. Edit `CLAUDE.md` only.

This is the reference application for dac-plane (dac-plane#97). Read `README.md`, then `tasks/plan.md`, then
`CONTRIBUTING.md`, whose rules apply to agents as to people. The most important one is the boundary: only
dac-plane's published contracts, never its source or database.

Run `just ci` before opening a pull request; CI runs the same recipes.
